## 📌 Project Overview
This repository features an **applied macroeconomic and personal finance model** developed independently during my **Class 12 Commerce** studies. The application systematically isolates and deconstructs the **"Money Illusion"**—the economic tendency to confuse nominal wages with real purchasing power across geographically diverse urban centers.

The core feature of this platform is a **side-by-side purchasing power comparison engine**. It allows users to input salaries and costs for two different cities simultaneously to instantly visualize which location offers a superior real quality of life after adjusting for local inflation.

## 📊 The Core Economic Formula
The underlying algorithmic logic of the application is governed by the following mathematical formulation:

$$\mathbf{D = \frac{I - N(1 + \frac{3}{m})}{G}}$$

### Variable Framework:
*   **I (Gross Monthly Income):** The baseline nominal fiat revenue stream.
*   **N (Composite Monthly Necessities):** Minimum fixed maintenance costs ($Rent + Food + Medical$).
*   **m (Liquidity Horizon Constraint):** The target time-horizon (in months) to systematically build a mandatory three-month safety cushion ($3N$).
*   **G (Geographic Cost Index):** The spatial deflation coefficient used to normalize localized cost-of-living premiums against baseline regional markets.
